# ERP Sistema Gráfico - Comunicação Visual e Sublimação

## 📋 Visão Geral

Sistema ERP web completo para gerenciamento de empresas de comunicação visual, sublimação e serviços gráficos. Desenvolvido com tecnologias modernas, arquitetura escalável e foco em usabilidade.

## 🎯 Objetivo

Substituir completamente planilhas, controles manuais e anotações, centralizando todas as informações da empresa em um único sistema moderno, intuitivo e profissional.

## 🏗️ Stack Tecnológico

### Frontend
- **Framework**: Next.js 14+ com App Router
- **Linguagem**: TypeScript
- **Styling**: Tailwind CSS + Shadcn/UI
- **State Management**: Zustand + React Query
- **Real-time**: WebSockets + Supabase Realtime
- **Hospedagem**: Vercel

### Backend
- **Framework**: NestJS
- **Linguagem**: TypeScript
- **Runtime**: Node.js 18+
- **Hospedagem**: Railway ou Render

### Banco de Dados
- **SGBD**: PostgreSQL
- **ORM**: Prisma
- **Armazenamento**: Supabase Storage / AWS S3
- **Autenticação**: Supabase Auth / Auth.js
